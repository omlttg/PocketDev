# PocketDev — Core Dev Agent (MVP 1)

**PocketDev** is a highly mobile, action-oriented software development assistant (Core Dev Agent) operating directly via Telegram. Powered by Gemini's advanced reasoning (Gemini 1.5/2.0) and integrated with GitLab's workspace capabilities, PocketDev enables CTOs, managers, and developers to manage repository branches, write issues, accept Merge Requests, and monitor CI/CD pipelines right from their mobile phones.

This project is built for the **"Building Agents for Real-World Challenges" Hackathon (GitLab MCP Server Track)**.

---

## 1. System Requirements & Installation

### Step 1: Clone the project and initialize a Python Virtual Environment
Open your terminal in the project directory and run:
```bash
# Create a virtual environment
python3 -m venv venv

# Activate the virtual environment
source venv/bin/activate

# Install dependencies
pip install -r requirements.txt
```

### Step 2: Configure Environment Variables
Create a `.env` file from the provided template:
```bash
cp .env.example .env
```
Open the `.env` file and populate it with your credentials:
* `GEMINI_API_KEY`: Obtain this from Google AI Studio.
* `TELEGRAM_BOT_TOKEN`: Chat with [@BotFather](https://t.me/BotFather) on Telegram to create a new Bot and get the token.
* `ALLOWED_TELEGRAM_USER_IDS`: Chat with [@userinfobot](https://t.me/userinfobot) to get your Telegram numerical user ID. Add it here to secure the bot (so only you can command it).
* `GITLAB_PERSONAL_ACCESS_TOKEN`: Create a token on GitLab under Settings -> Access Tokens with `api` scope.
* `GITLAB_PROJECT_ID`: The numeric ID of the GitLab project you wish to manage (visible on the project's home page).
* `WEBHOOK_SECRET_TOKEN`: A random alphanumeric secret token (e.g., `mysecret123`) to secure your webhook endpoint.

## 2. Run the Local FastAPI Server

To start the local webhook server:
```bash
uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```
Once started, you can access the high-fidelity Glassmorphic status dashboard at `http://localhost:8000` to verify your API connections.

## 3. Configure the Telegram Webhook

To connect Telegram to your local server, you will need to establish an HTTPS tunnel. We recommend using `ngrok`:

### Step 1: Run ngrok
```bash
ngrok http 8000
```
Copy the public HTTPS URL generated by ngrok (e.g., `https://xxx-xxx.ngrok-free.app`).

### Step 2: Register the Webhook URL with Telegram
Send a `GET` request using your browser or `curl` to register the webhook with Telegram:
```text
https://api.telegram.org/bot<TELEGRAM_BOT_TOKEN>/setWebhook?url=<NGROK_HTTPS_URL>/webhook/telegram/<WEBHOOK_SECRET_TOKEN>
```
**Example:**
```text
https://api.telegram.org/bot718290382:AAFlk.../setWebhook?url=https://1234-abcd.ngrok-free.app/webhook/telegram/mysecret123
```
If successful, you will receive a JSON confirmation:
```json
{
  "ok": true,
  "result": true,
  "description": "Webhook was set"
}
```

## 4. Suggested 3-Minute Demo Video Script (Mobile CTO Workspace)

Here is a walkthrough script demonstrating the core Agent-IDE coordination and team delegation capabilities:

1. **Introduction (CTO Mobile Portal):**
   * Send message: *"Hello PocketDev"*
   * The Agent responds as your Pocket CTO Agent, ready to coordinate team tasks and Cloud IDE Agents.
2. **IDE Agent Supervision (Cloud-based Antigravity IDE):**
   * Send message: *"Check Cloud IDE Agent status"*
   * The Agent calls `get_ide_agent_status` and displays the Cloud Agent logs, current active branch, and a pending code proposal `P-01` (Implement OAuth2 Google Login).
3. **Approve Code Proposal (Triggering CI/CD):**
   * Send message: *"Approve code proposal P-01"*
   * PocketDev calls `review_ide_agent_proposal(proposal_id="P-01", action="approve")`.
   * It logs the approval, calls GitLab API to accept the Merge Request, merges the code, and triggers the Pipeline run.
4. **Team Task Delegation (Group Chat Alerts):**
   * Send message: *"Assign task to dev_alex to implement Google OAuth frontend buttons"* (replace `dev_alex` with your team member's username).
   * PocketDev calls `assign_task_to_developer` which:
     * Creates a GitLab Issue assigned to `dev_alex`.
     * Automatically posts a notification in the **Team Telegram Group Chat**, tagging `@dev_alex` with the task description and GitLab Issue link.
